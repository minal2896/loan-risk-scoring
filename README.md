# Loan-prediction

"I worked on a supervised machine-learning classification project to predict loan status. I started with around 87,500 loan records containing financial, credit-history, employment and demographic features. I performed data cleaning, missing-value analysis, categorical encoding and feature engineering. During EDA, I found that the target variable was highly imbalanced, with approximately 81% versus 19% distribution, so I used SMOTE to address the imbalance. I then experimented with Logistic Regression, Random Forest, AdaBoost and Gradient Boosting. For Logistic Regression, I also performed statistical feature selection using p-values. I evaluated the models using accuracy, precision, recall, F1-score, confusion matrix, ROC-AUC and Cohen's Kappa. Gradient Boosting gave the best reported test performance, with approximately 89% accuracy and an AUC of 0.95."
